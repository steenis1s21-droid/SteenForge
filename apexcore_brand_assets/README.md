# Apexcore logo assets

## Recommended usage
- App icon / favicon: `apexcore-icon-*.png` or `apexcore-icon.svg`
- Dark UI: `apexcore-icon-dark.svg` / `apexcore-horizontal-dark.svg`
- Header/navigation: `apexcore-horizontal.svg`
- Monochrome fallback: `apexcore-icon-mono.svg` / `apexcore-horizontal-mono.svg`

## Suggested size mapping
- 16–24 px: favicon / tiny UI
- 32–48 px: compact navigation
- 64–128 px: sidebar/header
- 180–512 px: app icon / launch surfaces
- 1024 px: source/export master

## Brand colors
- Core indigo: #6366F1
- Dark background: #0A0E14
- White: #FFFFFF
- Monochrome dark: #111827

The SVG files are the preferred master assets for responsive UI.
